First release. The hybrid: original GOG/Steam 1.2.4 `Wiz8.exe` + `version.dll` + `wiz8hy.dll`,
installed by `Wiz8WideSetup.exe`.

## Sources

- this repository: the release tree (`patches\decomp-msvc2022.patch`, our changes to the
  decompilation, is kept locally and is not public);
- `decomp\` (separate local repository, source of `wiz8hy.dll`): tag `1.0.0` = commit `84a34ab`;
- the wide art and dgVoodoo files: `assets\` (not in git; identical to `files\Data` and the
  dgVoodoo files of the zip).

Builds are not byte-reproducible (timestamps): a rebuild from these sources gives the same
file list and the same non-built files, but different DLL hashes.

## Tested

Install and uninstall on clean copies of the Steam and GOG game (after uninstall the game
folder matches the original byte for byte); the Russian translation Wizardry8_rus (its `Data`
only) over the GOG exe, including the exit screen; a walk through the screens on a clean Steam
copy (menus, options, save/load, game, journal, map, camp, combat, spell and item panels,
character sheet, chest).
